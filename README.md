## Overview

This repository contains the source code for my personal portfolio website. It is a single-page application built with **React**, **Vite** and **Tailwind CSS**, designed to give recruiters and collaborators a quick, clear picture of who I am and what I build.

Every detail on the site comes from my resume, and all content is managed from a single data file, so updates are easy.

## Key Features

- **Fully responsive:** a polished layout on mobile, tablet and desktop, with a dedicated mobile menu
- **Light and dark themes:** a theme toggle in the navbar
- **Subtle scroll animations:** sections fade in as you scroll, and motion is reduced when the visitor's system asks for less motion
- **Active section tracking:** the navbar highlights the section currently in view
- **Project showcase:** real screenshots presented in browser-style frames
- **Working contact form:** opens the visitor's email app with the message pre-filled
- **Accessibility:** semantic HTML, keyboard navigation, visible focus outlines and a skip-to-content link
- **Single content file:** all text and links live in `src/data/portfolio.js`
